# Geological Institute in D-EAPS RadioCarbon and Cosmolab Calculator

## Try the workflow

1. [Requester](https://whitneybehr-design.github.io/gi-deaps-lab-demo/GI_DEAPS_labrequest.html). Enter fictional details and choose **Review request → Submit demo request**.
2. [Lab admin](https://whitneybehr-design.github.io/gi-deaps-lab-demo/GI_DEAPS_admin.html). Open the demo inbox and download a `GI_<surname>_<count>s_<short-id>.xlsx` file. Download the blank demo Master and try importing that request.
3. [Calculator editor](https://whitneybehr-design.github.io/gi-deaps-lab-demo/GI_DEAPS_calculator_editor.html). Edit a fee and choose **Save rates for this demo**, then open the requester page again to see it. Use **Restore published settings** to reset.

Demo requests and saved rates stay in the current browser, including when switching between pages or tabs. The demo pages are public and for fictional data only. The separately packaged GI deployment adds ETH sign-in and shared staff access.
