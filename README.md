# Geological Institute in D-EAPS RadioCarbon and Cosmolab Calculator

Researchers can [calculate costs and download an Excel request](https://whitneybehr-design.github.io/cosmolab-trial/). The email notification is a demo preview. The GI deployment package contains the separate private Master importer and instructions for hosting under GI ownership.

## Edit the calculator

1. Open the [calculator editor](https://whitneybehr-design.github.io/cosmolab-trial/#edit-calculator). Use the form to change fees, bulk discount rules, the instructions, or the demo email recipient.
2. Select **Preview in calculator**. Test a few sample counts and collaboration categories, then select **Back to editor**. The draft is held in this tab until you reload or close it.
3. Select **Download settings for GitHub**. Keep the filename `settings.json`.
4. Sign in to GitHub with a collaborator account and [upload the file to this repository](https://github.com/whitneybehr-design/cosmolab-trial/upload/main). Choose the option to create a new branch, then open a pull request. After review and merge to `main`, GitHub Pages publishes the new settings. Check the live calculator once the deployment finishes.

Repository owners can [invite editors](https://github.com/whitneybehr-design/cosmolab-trial/settings/access) by GitHub username. The trial settings are public. Keep customer request files and the Master tracker in the lab's private storage.
